# Bundled libraries

Shipped so `/present` output can run **fully offline**. Inline these into generated HTML for local mode, or use the CDN tags for online mode.

| File | Library | Version | License | CDN |
|------|---------|---------|---------|-----|
| `chart.umd.min.js` | Chart.js | 4.4.9 | MIT | `https://cdn.jsdelivr.net/npm/chart.js@4.4.9/dist/chart.umd.min.js` |
| `mermaid.min.js` | Mermaid | 10.9.1 | MIT | `https://cdn.jsdelivr.net/npm/mermaid@10.9.1/dist/mermaid.min.js` |

To update: re-download the matching version from jsDelivr and bump the versions here and in `references/authoring.md` + `SKILL.md`.
